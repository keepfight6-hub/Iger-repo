# Sungai Kapuas — explainer 60 dtk (9:16)

Gaya **Peta Relief Sinematik**, tanpa subtitle, tanpa efek suara. VO menyusul.

- `index.html` — video sebagai halaman web (semua frame dihitung dari waktu `t`).
- `hasil/` — MP4 hasil render.
- `tools/bake.py` — memanggang peta relief dari Natural Earth 1:10 jt (garis pantai & alur Kapuas asli;
  tinggi gunung, kedalaman laut, dan Danau Sentarum = perkiraan).
- `tools/render.js` — `node tools/render.js <url index.html> <out.mp4> 30 [t0] [t1] [vo.mp3]`.
